Vision Biomedical Services — Netlify-ready deployment package

Upload this ZIP directly to the existing Netlify site's manual deploy area.
The ZIP root already contains index.html, so the home page is the deployment root.

Included routes:
/
/about-us/
/services/
/regulatory-compliance/
/news/
/contact-us/
/careers/
/get-a-quote/

The production HTML files are self-contained. The assets/ folder is included as a complete safety copy of the source images/fonts/licenses.


Rebuild shared route entries after editing index.html: node build.cjs

To hide Career navigation later, set CAREERS_ENABLED = false in index.html and run node build.cjs.
The /careers/ page remains available when its navigation links are hidden.
